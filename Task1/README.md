# Задание 1. Анализ безопасности системы

## Cписок проблемных зон

- Хранение ПДн и медданных в Excel и файловых шарах
- Отсутствие шифрования данных при хранении.
- Отсутствие системы управления доступом, доступ есть у всех ко всем данным
- Нет журналирования доступа к медицинским данным
- Отсутствует система тегирования


## Список данных для защиты и способы защиты

| Данные                                        | Способы защиты                                                   |
| --------------------------------------------- | ---------------------------------------------------------------- |
| Персональные данные пациентов (ФИО, контакты) | Шифрование, маскирование, RBAC, аудит     |
| Медицинские данные (диагнозы, анализы)        | Шифрование (AES-256), обезличивание для аналитики, аудит доступа |
| Финансовые данные                             | Шифрование, контроль доступа, журналирование операций            |
| Данные сотрудников                            | Шифрование, разграничение прав, аудит                            |


## Механизм тегирования данных

| Тег     | Назначение           | Применение                           |
| ------- | -------------------- | ------------------------------------ |
| `PII`   | Персональные данные  | ФИО, телефон, e-mail                 |
| `MED`   | Медицинские данные   | Диагнозы, результаты анализов        |
| `FIN`   | Финансовые данные    | Платежи, счета                       |


## Инструменты защиты:

- Шифрование: TLS 1.2/1.3
- Контроль доступа: RBAC через Active Directory
- DLP: Microsoft Purview / Symantec DLP
