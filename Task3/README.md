# Задание 3. Оценка Data Encryption at Rest and In Transit

## Какие данные нужно защитить

| Данные                                 |  Чувствительность | Профиль риска                               |
| -------------------------------------- |  ---------------- | ------------------------------------------- |
| ПДн пациентов (ФИО, паспорт, контакты) |  Высокая          | Утечки, штрафы, репутационный ущерб         |
| Медицинские данные (диагнозы, анализы) |  Критическая      | Медтайна, юридические риски                 |
| Финансовые данные (платежи, счета)     |  Высокая          | Финансовые потери, мошенничество            |
| Учётные данные (логины, хеши паролей)  |  Критическая      | Несанкционированный доступ к аккаунтам      |
| Обезличенные аналитические данные      |  Низкая           | Низкий, если нет возможности деанонимизации |

## Автоматизированный контроль


Контроль утечек:


- DLP (Microsoft Purview / Symantec DLP) — поиск ПДН системах и файлах.

- Контроль выгрузок данных (массовый экспорт пациентов).

Аудит и мониторинг:


-SIEM (Wazuh / Splunk) — отслеживание подозрительных действий.

-Логи доступа к медицинским данным.

Контроль доступа:


-IAM (Active Directory / Keycloak).

-Политики ролей (RBAC): врач / администратор / бухгалтер.

## Реестр программных и аппаратных средств для защиты данных

| Тип              | Название                    | Назначение                           |
| ---------------- | --------------------------- | ------------------------------------ |
| Шифрование       | Hashicorp Vault             | Хранение ключей и токенов шифрования |
| Сетевая защита   | TLS 1.3 + VPN               | Защита данных при передаче           |
| Контроль доступа | Active Directory / Keycloak | Управление ролями и доступом         |
| DLP              | Microsoft Purview  / Symantec DLP         | Предотвращение утечек ПДН        |
| Анонимизация     | Python + Pandas             | Обезличивание аналитических данных   |

## Классификация данных

| Данные                    | В чем необходимость защиты                                          | Инструменты защиты                                                                                          |
| ------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Персональные данные  |  Выполнение ФЗ-152, защита от утечек, штрафов и репутационных рисков | 1) AES-256 шифрование БД/диска<br>TLS<br> |
| Медицинские данные   | Защита врачебной тайны, юридические риски                           | 1) AES-256 шифрование БД/диска<br>TLS<br>                        |
| Финансовые данные         |  Защита от мошенничества и утечек                                    |  AES-256 шифрование БД/диска<br> TLS<br> Ограничение доступа                                                        |
| Учётные данные            |  Защита от взлома аккаунтов                                          |  OAuth2/JWT<br> 2FA                                                     |
| Аналитические данные      |  Защита от утечек                                   | Обезличивание<br> Исключение ПДН
